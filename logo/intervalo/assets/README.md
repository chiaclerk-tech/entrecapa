# Entrecapa — El intervalo

Archivos maestros de la identidad aprobada.

- `entrecapa-mark.svg`: símbolo negro.
- `entrecapa-mark-white.svg`: símbolo blanco.
- `entrecapa-horizontal-black.svg`: firma horizontal negra con wordmark trazado.
- `entrecapa-horizontal-white.svg`: firma horizontal blanca con wordmark trazado.
- `entrecapa-stacked-black.svg`: firma apilada negra con wordmark trazado.
- `entrecapa-stacked-white.svg`: firma apilada blanca con wordmark trazado.

Las firmas están convertidas a curvas y no requieren ninguna fuente instalada. El wordmark parte de Manrope 650, distribuida bajo SIL Open Font License 1.1, con ajuste óptico y tracking propio.

Usar negro o blanco como versiones maestras. El color pertenece al sistema visual de Entrecapa, pero no es necesario para reconocer el logo.
